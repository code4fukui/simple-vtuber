# simple-vtuber

ウェブカメラを使用し、MediaPipe Face Meshによってシンプルでスタイライズされたアバターをリアルタイムにレンダリングする、軽量なブラウザベースのVTuberアプリケーションです。

## ライブデモ

**[https://code4fukui.github.io/simple-vtuber/](https://code4fukui.github.io/simple-vtuber/)**

このデモでは、目、眉、口などの顔の動きをトラッキングし、ミニマルなアバターをレンダリングします。ブラウザ上で直接アバターの外観をカスタマイズしたり、カメラビューを操作したりすることができます。

## 機能

- **リアルタイム顔トラッキング:** MediaPipe Face Meshを使用し、ウェブカメラの映像から478個の顔のランドマークを正確にトラッキングします。
- **スタイライズされたアバター:** ユーザーの表情に連動する目、眉、口と、カスタマイズ可能な顔色を備えたシンプルなベクターアバターをレンダリングします。
- **カスタマイズ可能なオーバーレイ:** 元のカメラ映像の表示/非表示の切り替え、メガネの追加、デバッグ用の顔メッシュの表示が可能です。
- **カメラコントロール:** 前面/背面カメラの切り替え、ミラーモードの有効化、ズーム操作が簡単に行えます。

## 使い方

1. 最新のウェブブラウザで[ライブデモ](https://code4fukui.github.io/simple-vtuber/)を開きます。
2. 要求されるカメラのアクセス権限を許可します。
3. 画面上のコントロールを使用してアバターをカスタマイズし、配信に利用します。

ローカルで実行する場合は、このリポジトリをクローンし、ブラウザで `index.html` ファイルを開いてください。

## コントロール

- **顔色:** カラーピッカーを開き、アバターの肌の色を変更します。
- **オリジナル画像の表示:** 背景のウェブカメラ映像の表示/非表示を切り替えます。
- **ミラーモード:** キャンバスを左右反転させます。
- **背面カメラモード:** デバイスの背面カメラに切り替えます。
- **デバッグ表示:** MediaPipeの生の顔ランドマークとテセレーションを表示します。
- **VTuberモード:** メインとなるスタイライズされたアバターのレンダリングのオン/オフを切り替えます。
- **メガネの描画:** アバターにメガネを重ねて表示します。
- **ズーム:** x1からx5までのズームレベルを選択します。
